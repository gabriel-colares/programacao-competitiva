# Como contribuir

Este repositório acompanha o ritmo do grupo de estudos. As contribuições devem
ser simples, legíveis e adequadas ao conteúdo já apresentado nas aulas.

## Antes de contribuir

- procure uma discussão ou issue existente sobre o assunto;
- não publique soluções de uma competição em andamento;
- não copie enunciados integrais sem verificar a licença do material;
- prefira uma descrição resumida, a atribuição da fonte e o link para o judge.

## Adicionando um exercício

1. Crie uma pasta numerada dentro da aula correspondente.
2. Inclua um `README.md` com fonte, objetivo, entrada, saída e conceitos.
3. Acrescente `dicas.md` quando dicas graduais ajudarem o aprendizado.
4. Sempre que possível, inclua um fluxograma acompanhado de descrição textual.
5. Coloque soluções de referência somente depois do material de apoio.
6. Teste a solução com os exemplos e com casos especiais.

Use nomes em minúsculas, sem espaços, como `01-zerinho-ou-um`.

## Padrão de código

- C++ deve compilar com C++17 e as opções `-Wall -Wextra -pedantic`.
- Use dois espaços para cada nível de indentação em C++.
- Coloque chaves em uma nova linha, inclusive em condicionais e laços.
- Nos materiais do grupo, prefira `using namespace std;` e `endl`.
- Python deve funcionar com Python 3.
- Não escreva mensagens como `Digite um número:` na saída.
- Use apenas a entrada e a saída especificadas pelo problema.
- Prefira nomes claros e soluções compatíveis com o nível atual do grupo.

## Pull requests

Explique o que foi adicionado ou corrigido e informe como o material ou código
foi verificado. Alterações devem se limitar a um objetivo claro.
