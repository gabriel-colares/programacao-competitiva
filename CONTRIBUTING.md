# Como contribuir

Este repositório acompanha o ritmo do grupo de estudos. As contribuições devem
ser simples, legíveis e adequadas ao conteúdo já apresentado nas aulas.

## Adicionando uma solução

1. Resolva e teste o problema por conta própria.
2. Coloque o arquivo na pasta da aula correspondente.
3. Use um nome curto que identifique o problema, sem espaços.
4. Inclua pelo menos um caso de teste com a saída esperada.
5. Explique a ideia e a complexidade quando a solução não for evidente.

## Padrão de código

- C++ deve compilar com C++17 e as opções `-Wall -Wextra`.
- Python deve funcionar com Python 3.
- Não escreva mensagens como `Digite um número:` na saída.
- Use apenas a entrada e a saída especificadas no enunciado.
- Prefira nomes claros e soluções compatíveis com o nível atual do grupo.

Não publique soluções de uma competição enquanto ela estiver em andamento.
