# Recursos online para começar do zero

Esta seleção é destinada a quem ainda não sabe programar. Não é necessário
concluir todos os cursos para participar das aulas: escolha um ponto de partida,
avance no seu ritmo e pratique os conceitos com problemas pequenos.

## Ordem recomendada

### 1. Entenda a lógica antes da linguagem

O [Curso de Algoritmos e Lógica de Programação](https://www.cursoemvideo.com/curso/curso-de-algoritmo/),
do professor Gustavo Guanabara, é a recomendação inicial. São 40 horas sobre
entrada, operadores, condicionais, repetições, funções, vetores e matrizes.

Combine o curso com nosso material de
[fluxogramas](fluxogramas.md). Antes de escrever código, tente representar cada
exercício com passos, decisões e setas.

### 2. Escolha uma primeira linguagem

O [Python 3 - Mundo 1](https://www.cursoemvideo.com/curso/python-3-mundo-1/),
também do Curso em Vídeo, foi preparado para pessoas sem experiência anterior.
Ele apresenta instalação, primeiros comandos, tipos, operações, textos e
condicionais por meio de exercícios.

Python possui uma sintaxe acessível e é uma boa linguagem para entender os
conceitos. Depois disso, a transição para o C++ usado nas competições fica mais
simples.

O Curso em Vídeo também mantém uma
[trilha para começar do zero](https://www.cursoemvideo.com/trilhas/comecar-do-zero-na-programacao/).

### 3. Aprofunde os fundamentos

O [CS50x - Introduction to Computer Science](https://cs50.harvard.edu/x/), da
Universidade Harvard, é gratuito no formato OpenCourseWare e não exige
experiência prévia. O curso começa com Scratch e depois aborda C, vetores,
algoritmos, memória, estruturas de dados e Python.

O CS50x é mais intenso do que os cursos anteriores. Recomendamos iniciá-lo após
compreender variáveis, condicionais e repetições. As aulas possuem uma
[opção oficial em português](https://cs50.ly/pt), mas parte do material de apoio
pode continuar em inglês.

### 4. Use um mapa, não uma lista de obrigações

Adotamos como referência o
[Computer Science Roadmap](https://roadmap.sh/computer-science), do roadmap.sh.
Ele organiza os fundamentos esperados de quem estuda Ciência da Computação de
forma autodidata.

Não tente completar o diagrama inteiro em sequência. Para acompanhar o grupo,
priorize:

1. lógica e fundamentos de programação;
2. estruturas de controle;
3. funções e recursão básica;
4. vetores, matrizes e strings;
5. complexidade, busca e ordenação;
6. estruturas de dados e algoritmos.

Sistemas operacionais, redes, bancos de dados e outros temas do roadmap são
importantes para a formação geral, mas não são pré-requisitos para começar em
Programação Competitiva.

## Como estudar

1. Assista a uma aula curta e anote os conceitos principais.
2. Refaça os exemplos sem consultar o vídeo.
3. Resolva ao menos um exercício no papel ou em fluxograma.
4. Implemente o mesmo raciocínio em Python ou C++ quando se sentir preparado.
5. Leve dúvidas e tentativas para as discussões do grupo.

Evite assistir a muitas aulas sem praticar. Programação é uma habilidade
construída principalmente pela resolução de problemas.
