# Acervo de provas

Esta área reúne cadernos oficiais para estudo e prática. Os arquivos estão
organizados por competição, ano e fase.

> O acervo contém somente os cadernos de problemas. Respostas, gabaritos e
> soluções não são incluídos por enquanto.

## Competições

- [Olimpíada Brasileira de Informática](obi/README.md)
- [Maratona de Programação da SBC](maratona-sbc/README.md)

Os direitos sobre os cadernos pertencem às respectivas organizações. Os
arquivos são mantidos aqui como material de estudo, com sua origem identificada.
