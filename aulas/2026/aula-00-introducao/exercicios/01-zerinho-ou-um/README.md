# 01 - Zerinho ou Um

**Fonte:** Maratona de Programação da SBC

**Judge:** [beecrowd 1467](https://judge.beecrowd.com/pt/problems/view/1467)

**Categoria:** Ad-Hoc

**Dificuldade sugerida:** iniciante

## Objetivo

Dados os valores escolhidos por Alice, Beto e Clara, determine quem escolheu um
valor diferente dos outros dois. Caso não exista um jogador diferente dos
demais, não há vencedor.

Esta é uma descrição resumida para orientar o estudo. Consulte o link do judge
para acessar o enunciado oficial e submeter sua solução.

## Entrada

Cada caso possui três valores, `A B C`, e cada valor é `0` ou `1`. Existem
vários casos de teste e a entrada termina em EOF.

## Saída

Para cada caso, imprima:

- `A` caso Alice vença;
- `B` caso Beto vença;
- `C` caso Clara vença;
- `*` caso não exista vencedor.

## Conceitos trabalhados

- interpretação de enunciado;
- condicionais;
- entrada e saída;
- EOF;
- casos especiais.

## Antes de programar

1. Em quais situações Alice vence?
2. Em quais situações Beto vence?
3. Em quais situações Clara vence?
4. Quando ninguém vence?
5. Quantas combinações diferentes existem?
