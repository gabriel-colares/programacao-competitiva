# 02 - Elevador

**Fonte:** Olimpíada Brasileira de Informática 2026, fase 1, nível Sênior

**Categoria:** simulação

**Dificuldade sugerida:** iniciante

## Enunciado

O elevador visita `N` andares em uma ordem conhecida. Como leva um segundo para
percorrer um andar, determine o tempo total do percurso.

O enunciado oficial está no [caderno da OBI 2026, nível Sênior, fase 1](../../../../../provas/obi/2026/senior/fase-1.pdf).

Se precisar de orientação, abra as [dicas progressivamente](dicas.md). O
exercício continua sem código, casos de teste ou solução de referência.
